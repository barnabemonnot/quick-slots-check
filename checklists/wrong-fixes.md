# Wrong fixes that look correct

Each row was seen in at least one real system (CHECKED code for the examples behind each row). The "how to recognise
it" column is guidance (INFERRED). IDs W1-W10 are stable.

| ID | Wrong fix | What goes wrong at 10 s | Correct fix | How to recognise it |
|---|---|---|---|---|
| <a id="w1"></a>W1 | **Constant 10, genesis anchor kept.** A duration constant, setter or override flag set to 10 while `genesis_time` is unchanged. | Clock 0.2F slots (about one year) ahead. One oracle report could add 9.9-17.3 % of a pool's value; a light-client guard becomes void; blob requests return 404. | Piecewise schedule; or set `d` and `G'` together in one call. | Test: the slot at `T_F` must be `F`, not `1.2F`. |
| <a id="w2"></a>W2 | **Fork-version-only release.** Adds the Heze fork version or digest, keeps the clock. | Fresh light-client updates rejected from about 1 min. | Fork-aware clock in the same release. | Release notes list only the fork version. Test: accept an update signed at `T_F + 60 s`. |
| <a id="w3"></a>W3 | **Library bump, one-duration API.** A build error at a single-duration clock constructor or getter, "fixed" by passing one constant. | The port keeps 12 s. | A schedule-aware constructor; deprecate the old calls. | The port passes one constant. Test: vectors through the real caller. |
| <a id="w4"></a>W4 | **Partial fix of a shared clock.** `current_slot()` changes, but deadlines, timers, caches or a second component do not. | Self-rejection, honest ejections, rotation stuck, a cache that never refreshes, no relay reveal from F+4. | Change all parts in one release. | A diff that changes the slot function but not the timers. |
| <a id="w5"></a>W5 | **Legacy key switch; key-name fallback.** A beacon node serves 10 in `SECONDS_PER_SLOT`; a config reader accepts a missing or misnamed key. | Readers about one year ahead after restart; silent 12 s; a chain split on file-configured networks. | Keep genesis values; freeze the name (R2, R3). | `SECONDS_PER_SLOT != 12` after the fork; a key other than `SLOT_DURATION_MS_HEZE` accepted with no error. |
| <a id="w6"></a>W6 | **Clock switch without migration.** Block-based accrual or governance switched to timestamps. | 55-66 years of interest at once; borrows x4.48 or x13.53; votes end at once. | Keep the clock and rescale (rates x5/6 at `T_F` with a fork-aware switch; windows x1.2 via the setter before the fork). No proposal open during a clock change. | A clock-mode switch with no checkpoint reset; an open proposal at the switch. |
| <a id="w7"></a>W7 | **Wrong timing; value assumed final.** An admin call or payload before `T_F` with no fork guard; 10 s treated as final before R9. | Liveness loss; votes 16.7 % shorter; a payload executable 14 d early; 1,350 epochs wrong 30 d after the fork if the value stays 12 (2,025 if it becomes 8). | Use the class window; runtime parameters; wait for R9. | A queued action with no fork guard. |
| <a id="w8"></a>W8 | **One side of a pair.** A producer fix without its consumers, or the reverse. | L2 rate updates revert after 5.0 d; a convenience call reverts. | Find all consumers; move both sides together. | You produce a 12 s value and do not know its consumers. |
| <a id="w9"></a>W9 | **Exact fork-name gates; one part of a pipeline.** `== ForkName::Gloas`; only the challenger upgraded; a fork name in the wrong case in config. | The gated path switches off at the next fork; a stale prestate. | `>=` fork comparisons; test the full stack on a post-fork block. | `== ForkName::X` in code; only one binary of a pipeline in the upgrade plan. |
| <a id="w10"></a>W10 | **Disable a safety check to get unstuck.** Slashing protection, checkpoint age, weak subjectivity or future-slot checks turned off when a wrong clock trips them. | The clock stays wrong and the safety loss remains. Deleting or resetting slashing protection, or moving keys while the old signer may still run, can cause a slashable double signature. | Fix the clock source; keep every check; use the vendor's documented recovery. | A flag such as `ignore-ws`, `strict_checkpoint_age=false` or a wiped slashing database in a runbook. |

`check/scan.py` flags candidate code for W1 (GEN-SLOT-DURATION-10, GEN-OVERRIDE-FLAG), W3 (GEN-SINGLE-DURATION-API)
and W9 (GEN-FORK-NAME-EQ). The [vectors](../vectors/README.md) detect W1 and the virtual-genesis variant by their exact
fingerprints.
